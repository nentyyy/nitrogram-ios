# Моды Nitrogram для iOS

Мод — **один файл `.ngmod`**, который можно переслать в чате, импортировать в
приложении и удалить в любой момент. Клиент не содержит логики конкретных модов,
он только загружает и запускает их.

---

## 1. Чем iOS отличается от Android

На Android мод — это `.so` с вшитым DEX, который грузится через `System.load`.
**На iOS так нельзя**: подпись кода запрещает загрузку произвольных нативных
библиотек, и сайдлоад этого не меняет.

Поэтому логика мода на iOS пишется на **JavaScript** и исполняется системным
`JavaScriptCore` — интерпретация разрешена, JIT не требуется. Контракт при этом
сохранён: те же `apply()` / `applySettings(json)`, те же метаданные с иконкой.

Второе отличие — **экран настроек декларативный**. На Android мод строил `View`
сам, потому что был байткодом той же платформы. Здесь мод описывает поля в JSON,
а клиент рисует их родными компонентами: единый стиль и мод не может сломать UI.

| | Android | iOS |
|---|---|---|
| Файл мода | `lib<id>_fx.so` | `<name>.ngmod` |
| Логика | Java → DEX внутри `.so` | JavaScript |
| Сборка мода | JDK + d8 + clang + NDK | не нужна, это текстовый файл |
| Экран настроек | мод строит `View` | мод описывает JSON-схему |
| Точки входа | `apply`, `applySettings` | те же |

Сборка мода на iOS не нужна вообще: `.ngmod` — это JSON, его можно написать
в любом редакторе.

## 2. Формат файла

```json
{
  "format": 1,
  "name": "Example Greeter",
  "description": "Logs a greeting whenever a chat is opened.",
  "version": "1.0",
  "author": "Nitrogram",
  "extra": "Любая дополнительная информация.",
  "icon": "<base64 PNG или JPEG, без префикса data:>",
  "settings": [ ... ],
  "source": "<JavaScript>"
}
```

Обязательны только `name` и `source`. Идентификатор мода вычисляется из
`name` + `version`, поэтому повторный импорт **обновляет** карточку, а не плодит
дубликаты, и сохранённые настройки при этом не теряются.

---

## 3. Схема настроек

Каждый элемент массива `settings` — одна строка на экране настроек:

```json
{"key": "loud",      "type": "switch",    "title": "Shout it",  "default": false}
{"key": "intensity", "type": "slider",    "title": "Intensity", "min": 0, "max": 1, "step": 0.05, "default": 0.7}
{"key": "mode",      "type": "segmented", "title": "Mode",      "options": ["Soft", "Hard"], "default": "Soft"}
{"key": "greeting",  "type": "text",      "title": "Greeting",  "placeholder": "hello", "default": "hello"}
```

Поддерживается необязательный `subtitle`. Элемент с неизвестным `type`,
без `key` или с некорректным диапазоном молча пропускается — остальной мод
продолжает работать.

## 4. Контракт мода

```js
// Вызывается один раз при включении мода.
function apply() { }

// Вызывается при включении (с сохранёнными значениями)
// и каждый раз при изменении настройки.
function applySettings(json) {
    var values = JSON.parse(json);
}

// Необязательно. Вызывается при выключении мода.
function unapply() { }
```

## 5. API хоста

Каждому моду доступен глобальный объект `Nitrogram`:

| Вызов | Назначение |
|---|---|
| `Nitrogram.log(text)` | Записать строку в журнал модов. |
| `Nitrogram.on(event, fn)` | Подписаться на событие хоста. |
| `Nitrogram.mod.id` / `.name` / `.version` | Информация о самом моде. |
| `Nitrogram.settings.get(key)` | Текущее значение настройки. |
| `Nitrogram.settings.set(key, value)` | Изменить и сохранить настройку. |

События:

| Событие | Состояние |
|---|---|
| `modsLoaded` | работает — при старте включённых модов |
| `appDidBecomeActive` | работает |
| `appWillResignActive` | работает |
| `chatOpened` | объявлено, **пока не вызывается** |
| `messageSent` | объявлено, **пока не вызывается** |
| `messageReceived` | объявлено, **пока не вызывается** |

Последние три доставляются подписчикам корректно, но точки в приложении,
которые их порождают, ещё не подключены — подписка на них сейчас просто
никогда не сработает.

## 6. Изоляция и безопасность

- У каждого мода **свой** `JSContext` — моды не видят переменных друг друга.
- Мод исполняется на отдельной последовательной очереди, **не на главном потоке**:
  зациклившийся мод не подвесит интерфейс, хотя и займёт одно фоновое ядро.
  У `JavaScriptCore` нет публичного сторожевого таймера, поэтому изоляция потока —
  реальная доступная защита, а не полное решение.
- Импортированный мод **выключен** до тех пор, пока пользователь его не включит.
- Моду доступно только то, что явно отдано через объект `Nitrogram`: ни файловой
  системы, ни сети, ни доступа к переписке.

---

## 7. Установка

1. Пришлите себе `.ngmod` в чат или положите в «Файлы».
2. Nitrogram → «Моды» → импортировать.
3. Включите мод переключателем; шестерёнка появится, если у мода есть настройки.

Правки логики достаточно сохранить в файл и импортировать заново — версия та же,
карточка обновится на месте.
